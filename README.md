# 📦 Size Compressor

A modern web application to compress different types of files.

## Features

- 🖼️ Image Compressor
- 📄 PDF Compressor
- 📊 PPT Compressor
- 🎥 Video Compressor
- 🎵 Audio Compressor

## Technologies Used

- HTML5
- CSS3
- JavaScript
